Pipeline

          

            
AgentJob

            
ClarificationAsks a few targeted questions, falls back to defaults if skipped

            
PlannerTurns the spec into a page/component/dependency plan

            
UI ArchitectLays out the folder and file structure

            
ComponentGenerates each component's code, using RAG-retrieved docs as context

            
StylingWrites the global theme and tags each component with its color preset

            
Package ManagerResolves dependencies and writes package.json

            
ReviewerRuns static checks and an LLM pass over the generated code

          

        

        

          
Real build, real preview

          
This backend runs on a Docker image with both Python and Node.js, so npm install and npm run build run for real, and the built app is served from this same server under /preview/<session>/ — no separate port to expose.

        

        

          
Style swapper

          
Swapping a theme replaces the Tailwind color class names already in the generated code (not a re-generation), then triggers a fast rebuild so the real preview reflects it in a few seconds.
